# Worklog — трекер продуктивности

PWA-дашборд для отслеживания времени, проектов и планов.
Данные шифруются AES-256-GCM, PIN — ключ.

## URL
- Дашборд: https://masterboplus-netizen.github.io/worklog/
- Репо: https://github.com/masterboplus-netizen/worklog

## Локально
python3 encrypt.py

## Установка на телефон
1. Открыть URL
2. Ввести PIN
3. Добавить на главный экран
