## 📝 Как записывать сессии (Инструкция для ИИ)

**ВАЖНО:** Никогда не пишите сессии вручную в JSON. Используйте только скрипт `add_session.py`. Он сам посчитает время, проверит дубли, зашифрует данные и запушит в GitHub.

### Команда для добавления сессии:

```bash
cd ~/workspace/worklog-app && python3 add_session.py \
  --date "ГГГГ-ММ-ДД" \
  --start "ЧЧ:ММ" \
  --end "ЧЧ:ММ" \
  --project "ID_проекта" \
  --events 0 \
  --screens 0 \
  --tasks 0 \
  --note "Текст заметки"
```

### Правила:
1. Если сессия переходит через полночь (например, 23:00 - 01:00), скрипт сам разобьет её на две части.
2. Если время пересекается с уже существующей сессией, скрипт выдаст ошибку и ничего не запишет.
3. Пароль для шифрования (201186) уже вшит в скрипт.
