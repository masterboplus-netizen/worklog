# SAFE_DIAL_SPEC — Слепой сейф (PIN-кольцо)

> Дата: 2026-10-29. Статус: реализация (переписано с нуля).
> Проект: Хераборина (worklog-app). Не смешивать с Бо 8.1.

## 1. Концепция
Вход — жест по кольцу. На экране одно ярко-оранжевое кольцо, без цифр и подсказок.
Владелец зажимает палец в зоне кольца, ведёт по часовой, делает 3 остановки в нужных секторах.

## 2. Визуал
- Кольцо: толщина 30px, радиус 90px (диаметр ~220px), цвет #FFA500, drop-shadow.
- Лупа: оранжевый круг r=25px под пальцем, следует за пальцем.
- Подсветка активного сектора (1/12). Зелёного нет — только оранжевое кольцо.
- По центру экрана, `touch-action: none` на контейнере.

## 3. Механика (финал)
1. `touchstart` → `SAFE_INPUTS = []`, появляется лупа, фиксируется угол.
2. `touchmove` → угол = `Math.atan2(y-cy, x-cx) + 90°`, нормализация [0,360).
3. Сектор = `Math.floor(angle / 30)` (0..11), 0 = 12 часов, 3 = 3 часа, 6 = 6 часов, 9 = 9 часов.
4. При входе в **целевой** сектор — `navigator.vibrate(20)` **сразу** (внутри touchmove, не в таймере).
5. Таймер 600 мс на текущий сектор. Ушёл раньше → таймер сброшен, сектор не засчитан.
6. Засчитан → `SAFE_INPUTS.push(true)`, «щелчок» (короткий scale). Если сектор не целевой —
   `SAFE_INPUTS.push(false)` не нужен: сразу ошибка (см. п.8).
7. Нужно 3 остановки в порядке **5 → 11 → 2**.
8. Ошибка (неверный сектор или порядок): красная вспышка + вибрация, `SAFE_INPUTS = []`,
   пользователь **остаётся на кольце**, начинает заново.
9. Все 3 верны → `tryUnlock('201186')` → успех → `showScreen('dashboard')` + `renderDashboard()`.

## 4. Правильные зоны (секторы)
- Точка 1: сектор **5** (150°–180°, 5–6 часов)
- Точка 2: сектор **11** (330°–360°, 11–12 часов)
- Точка 3: сектор **2** (60°–90°, 2–3 часа)
Порядок важен: `[5, 11, 2]`.

## 5. Грабли и решения
- НЕ использовать `transform: rotate` на SVG. Угол считать через `atan2 + 90°` в JS.
- `navigator.vibrate` вызывать только в `touchstart`/`touchmove`, не в `setTimeout`.
- `SAFE_INPUTS = []` в каждом `touchstart`.
- Лупа: контейнер `position: relative`, лупа `position: absolute; pointer-events: none`.
- Кэш: поднимать `?v=N` в `index.html` И `CACHE` в `sw.js`.
- iOS Safari: вибрации нет (ограничение Apple), сейф работает без неё.

## 6. Файлы
- `index.html` — `#scroll-pin-screen`, SVG кольцо, хитбокс, лупа.
- `css/components.css` — блок «СЛЕПОЙ СЕЙФ (v2)».
- `js/safe.js` — вся логика кольца.
- `app.js` — `init()` вызывает `showSafe()` вместо прямого `tryUnlock`.
- `sw.js` — добавить `./js/safe.js` в ASSETS, поднять CACHE.
