# CODE_MAP — карта кода Хераборины

> Обновлено: 2026-10-28
> Номера строк плавают — всегда сверять через grep -n.

## Файлы (основные)
- `app.js` — Дирижер. Инициализация, вкладки, логика входа (сейчас PIN-код), модалки создателей.
- `js/ui.js` — Отрисовка дашборда (кольца), дневника (календарь).
- `js/chart.js` — Отрисовка графика (лента, тултип, метрики).
- `js/auth.js` — Логика PIN-кода (расшифровка).
- `css/components.css` — Стили компонентов (график, кольца, календарь).
- `crypto.js` — Шифрование/расшифровка (AES-256-GCM).
- `encrypt.py` — Скрипт шифрования данных перед пушем.

## app.js — ключевые функции
- `init()` — старт приложения (показывает PIN-экран).
- `switchTab(name)` — переключение вкладок.
- `showJoke()` / `closeJoke()` — пасхалка в профиле.
- `showCreators()` — модалка с авторами.
- `showScreen(name)` — управление видимостью экранов (pin, dashboard, loading).

## js/ui.js — ключевые функции
- `renderDashboard()` — сборка главного экрана.
- `renderHeroRings()` — отрисовка колец (математика прогресса).
- `renderRingSVG()` — генерация SVG-круга (прогресс, цвет).
- `renderDiary()` — отрисовка календаря и списка сессий.

## js/chart.js — ключевые функции
- `renderActivityPageV2()` — сборка страницы графика.
- `updateChart()` — пересчет данных и отрисовка столбиков.
- `renderChart()` — генерация HTML для столбиков (используется в старом коде).
